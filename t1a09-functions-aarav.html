02 / GAME SCORE

Calculate a level score.

Enter the coins and enemies collected in a level. Two reusable functions work together to calculate your score and award a rank.

LEVEL RESULT
Your score and rank will appear here.
FUNCTIONS AT WORK
function myCalculateScore(coins, enemies) {
  return coins * 10 + enemies * 25;
}

function myRank(score) {
  if (score >= 200) return "Gold";
  if (score >= 100) return "Silver";
  return "Bronze";
}

const score = myCalculateScore(5, 2);
myRank(score); // Silver

What this example shows
