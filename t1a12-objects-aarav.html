Objects

Explore how JavaScript objects group related properties.

Getting to know objects

What is an object?

An object groups related data as named properties. A property can also contain a function, called a method.

Reference: MDN: Working with objects

01 / TRY IT

Explore an object

Read the properties of a person object using dot notation.

RESULT
The person's properties will appear here.
JAVASCRIPT EXAMPLE
const myPerson = { firstName: "John", lastName: "Doe", age: 50, eyeColor: "blue" };
function myShowPerson() {
  document.getElementById("myDiv01").textContent = myPerson.firstName + " " + myPerson.lastName + " is " + myPerson.age + " years old and has " + myPerson.eyeColor + " eyes.";
}

02 / CHANGE A PROPERTY

Customize a player

Change the player's name, then use the object method to collect a point. The object keeps its updated values until you reset it.

PLAYER OBJECT
Aarav has 0 points.
OBJECT METHODS
const myPlayer = {
  name: "Aarav",
  points: 0,
  collectPoint() {
    this.points += 1;
  }
};

myPlayer.name = "Aarav";
myPlayer.collectPoint();

NICHE JAVASCRIPT / A CLOSER LOOK

Copy nested objects

structuredClone() makes an independent deep copy of supported values. Changing a nested property on the copy does not change the original.

RESULT
Try the example to see the result.
HOW IT WORKS
const copy = structuredClone(original);
copy.inventory.coins = 5;
// original.inventory.coins is still 1
