02 / ROLL THE DICE

Roll for a six.

Roll a three-dimensional die. A conditional checks the result and celebrates when you land a six.

YOUR ROLL
Ready to roll.

The die uses crypto.getRandomValues() and rejection sampling to choose an unbiased face. In an insecure context, it falls back to Math.random().

DECISIONS IN ACTION
const roll = myRandomFace();
if (roll === 6) {
  celebrate();
} else {
  showRoll(roll);
}

NICHE JAVASCRIPT / A CLOSER LOOK

Random values and bias

crypto.getRandomValues() supplies random bytes. Since 256 is not divisible by 6, discarding values 252 to 255 before taking the remainder gives each face the same number of possible byte values.

RESULT
Try the example to see the result.
HOW IT WORKS
do { crypto.getRandomValues(bytes); }
while (bytes[0] >= 252);
const face = bytes[0] % 6 + 1;
