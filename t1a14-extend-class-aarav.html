Extending classes

Build on a class and customize its behavior.

Getting to know inheritance

What does extending a class mean?

A subclass inherits behavior from a parent class. It can also add its own methods or override inherited ones.

Reference: MDN: extends

01 / TRY IT

Meet the parent class

Create an animal and display the description provided by its class.

RESULT
The animal's description will appear here.
JAVASCRIPT EXAMPLE
class myAnimal {
  constructor(myName, myAge) {
    this.myName = myName;
    this.myAge = myAge;
  }
  myShow() { return this.myName + " is " + this.myAge + " years old."; }
}
class myCat extends myAnimal {
  myShow() { return this.myName + " is a cat and is " + this.myAge + " years old."; }
}
function myShowAnimal() {
  const myDog = new myAnimal("Snickers", 5);
  document.getElementById("myDiv01").textContent = myDog.myShow();
}
function myShowCat() {
  const myPet = new myCat("Fluffy", 14);
  document.getElementById("myDiv02").textContent = myPet.myShow();
}

02 / BUILD A SUBCLASS

Train a dog

Create a three-year-old dog with its own trick. Its subclass uses the animal constructor, then adds and changes a property of its own.

YOUR DOG
Create a dog to get started.
EXTENDING A CLASS
class myDog extends myAnimal {
  constructor(myName, myAge, myTrick) {
    super(myName, myAge);
    this.myTrick = myTrick;
  }

  myTeach(myTrick) {
    this.myTrick = myTrick;
  }
}

const myPet = new myDog("Scout", 3, "sit");
myPet.myTeach("roll over");

THE TAKEAWAY

What these examples show

  • Create instances of a parent class and a subclass.
  • Use extends to inherit from a class.
  • Override an inherited method in a subclass.
  • Use super and a subclass method to initialize and update a new property.
