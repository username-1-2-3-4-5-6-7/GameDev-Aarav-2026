NICHE JAVASCRIPT / A CLOSER LOOK

Pause a loop with a generator

A generator function can yield one value at a time. Each call to next() resumes the loop until its next yield, so you can step through it yourself.

RESULT
Try the example to see the result.
HOW IT WORKS
function* count() {
  for (let i = 0; i < 3; i++) yield i;
}
const counter = count();
counter.next();
