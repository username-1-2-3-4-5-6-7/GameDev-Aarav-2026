Getting to know classes

What is a class?

A class is a blueprint for creating objects with shared behavior. Its constructor initializes each instance, and its methods define what it can do.

Reference: MDN: Classes

01 / TRY IT

Create an animal

Create an animal named Snickers, then call its method to display its details.

RESULT
The animal's details will appear here.
JAVASCRIPT EXAMPLE
class myAnimal {
  constructor(myName, myAge) {
    this.myName = myName;
    this.myAge = myAge;
  }
  myShow() { return this.myName + " is " + this.myAge + " years old."; }
}
function myShowAnimal() {
  const myDog = new myAnimal("Snickers", 5);
  document.getElementById("myDiv01").textContent = myDog.myShow();
}

02 / WORK WITH AN INSTANCE

Create your own animal

Choose a name and age to create an instance. Then call its birthday method to update its age.

YOUR ANIMAL
Create an animal to get started.
INSTANCE METHODS
class myPet extends myAnimal {
  myBirthday() {
    this.myAge += 1;
  }
}

const myPetInstance = new myPet("Milo", 3);
myPetInstance.myBirthday();
myPetInstance.myShow();
